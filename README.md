# SERVEASE — Verified Home Service Booking Platform (Prototype)

**Live prototype:** https://servease-app.netlify.app/

SERVEASE is a mobile app concept that connects users with verified home repair technicians (AC, electrical, plumbing, carpentry, appliance service) through a trust-first booking experience — transparent pricing, technician verification, and service guarantees, in a market still dominated by word-of-mouth and unverified WhatsApp contacts.

This prototype was developed as part of a business case project at IPB University's School of Business, combining business model design with UI/UX prototyping.

## Problem

Home repair services in Indonesia remain largely informal: customers struggle to verify technician credibility, face non-transparent pricing, get slow response times during emergencies, and have no formal service guarantee. Interviews conducted for this project (with kos residents, homeowners, and boarding house owners in Bogor) confirmed these as high-pain points — 100% of respondents expressed interest in switching to a verified platform with upfront cost estimates.

## Solution

SERVEASE is a one-stop platform where users can:
- Browse and filter verified technicians by category (AC, electrical, plumbing, carpentry, appliances)
- View technician ratings, completed jobs, and response time before booking
- See transparent, itemized price estimates upfront (no hidden fees)
- Book a technician and track order status from confirmation to completion
- Receive a 7–14 day service guarantee after the job is done

## Key Features (Prototype)

- Login flow
- Home dashboard with service categories and nearby technicians
- Technician search with filtering
- Technician profile with ratings, reviews, and price breakdown
- Booking flow with schedule selection and itemized cost summary
- Active order tracking with technician location and guarantee status

## My Role — Product Development

## Tech Stack

Built as a front-end prototype using HTML, CSS, and JavaScript, hosted on Netlify. This is a UI/UX and business-model prototype — it demonstrates the intended user flow and interface but is not yet connected to a backend, database, or payment system.

## Status

🚧 **Prototype stage.** Core screens and navigation flow are functional and clickable. Booking, ratings, and order history are simulated with local data. Not yet connected to a live backend, real technician data, or payment processing.
